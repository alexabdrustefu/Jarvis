# Changelog

All notable project changes are recorded here.

## 0.1.0 — 2026-10-24

- Initial open-source release of the Windows desktop assistant.
- Added local AI providers for Ollama and LM Studio, with optional Groq support.
- Added SQLite-backed chat memory, reminders, tasks, routines, and local preferences.
- Added the CustomTkinter desktop interface, local HTTP/WebSocket API, and JSON TCP bridge.
- Added RSS news, Open-Meteo weather, optional Gmail summaries, and Windows actions.
- Added Windows installer and portable archive release pipeline.
- Added unit tests, Ruff checks, Dependabot, issue forms, and protected release branches.
- Added an offline demo mode and a guided walkthrough for first-time users.
