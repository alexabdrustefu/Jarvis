# Segnalazione di vulnerabilità

Non pubblicare vulnerabilità, credenziali esposte, token o dati personali in una issue pubblica.

Se la segnalazione privata di vulnerabilità è disponibile nella scheda **Security** del repository, usala. In caso contrario contatta privatamente il proprietario del repository prima di rendere pubblici i dettagli. Includi soltanto le informazioni necessarie a riprodurre il problema e rimuovi sempre segreti e dati di terzi.
