# Roadmap

The roadmap captures current direction, not fixed delivery dates. Contributions and user feedback can change priorities.

## Shipped — 0.1.0

- Windows desktop chat and animated dashboard.
- Offline demo mode for trying the interface without accounts, keys, network, or microphone.
- Ollama and LM Studio local providers, with optional Groq support.
- Local SQLite memory, reminders, tasks, routines, and settings.
- Local HTTP, WebSocket, and newline-delimited TCP interfaces.
- Windows installer and portable release artifacts.

## Next — 0.2.0

- First-run setup that detects Ollama and guides model installation.
- More explicit connection and privacy status for each provider and action.
- Real, optimized screenshots and a short walkthrough video captured from the demo build.
- Broader automated coverage for the installer and supported Windows versions.
- English UI strings and a lightweight localization structure.

## Later

- A small web client that uses the existing local HTTP and WebSocket APIs.
- Provider capability and health checks with clearer fallback explanations.
- More integrations that remain optional and disabled until explicitly configured.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for the branch, pull request, test, and release workflow. The issue tracker is the place to discuss and pick up roadmap tasks.

# Roadmap in italiano

La roadmap descrive la direzione attuale, non date di consegna vincolanti. Feedback e contributi possono cambiarne le priorità.

## Disponibile — 0.1.0

- Chat desktop Windows e dashboard animata.
- Demo offline senza account, chiavi, rete o microfono.
- Provider locali Ollama e LM Studio, con Groq facoltativo.
- Memoria SQLite, promemoria, attività, routine e preferenze locali.
- Interfacce locali HTTP, WebSocket e TCP delimitata da newline.
- Installer Windows e archivio portatile nelle release.

## Prossimo — 0.2.0

- Configurazione iniziale con rilevamento di Ollama e guida all'installazione del modello.
- Stato più chiaro di connessioni, privacy e azioni per ogni provider.
- Screenshot reali ottimizzati e breve video registrati dalla demo.
- Maggiore copertura automatica dell'installer e delle versioni Windows supportate.
- Traduzione inglese della UI e struttura leggera per la localizzazione.

## In seguito

- Client web leggero basato sulle API HTTP e WebSocket locali.
- Controlli di disponibilità dei provider e spiegazioni più chiare dei fallback.
- Altre integrazioni facoltative, disattivate finché non vengono configurate.

Per contribuire, consulta [CONTRIBUTING.md](CONTRIBUTING.md) e le issue del repository.
